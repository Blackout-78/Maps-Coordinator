Maps Coordinator v0.2.0: names and detail.

Added:
- Street names along the roads, and highway numbers.
- City, town, village and neighborhood names.
- Businesses (restaurants, shops, fuel, hotels, health) with a colored dot and name.
- House numbers and building outlines when zoomed in.
- Speed limit signs on roads that have a posted limit.

IMPORTANT: names and detail are saved during import, so you must re-import your map file. Open Settings, tap Delete all maps, then Import map file again.

The map file now takes longer to import and uses more space because buildings and businesses are included. Detail only loads when you zoom in.
