First build of Maps Coordinator.

Added:
- Offline map from a file you import (OpenStreetMap .osm.pbf): city streets, dirt roads, trails, water, stop signs.
- Your live position from the phone's GPS, shown as MGRS (WGS 84) with heading, speed, elevation and declination.
- Night theme.
- Settings with version, Open GitHub Releases button, and credits.

No internet permission. Nothing leaves the phone.

Known limits in this version: lane lines and speed limit signs are stored but not drawn yet; no 3D view, military tools or Learn section yet.
